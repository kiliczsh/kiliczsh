### 🌱 About Me

- 👋 Hi, I'm **Kılıç**, a software carpenter. I craft solutions for today and sketch blueprints for tomorrow.
- 🔧 I build **scalable, efficient applications** that solve real-world problems, the kind of work that leaves the shop cleaner than I found it.

### 🧪 Featured Projects

- 🎨 [**genui**](https://github.com/kiliczsh/genui)
  Workspace and architecture hub for native A2UI generative interfaces: an ecosystem spanning a [versioned protocol](https://github.com/kiliczsh/genui-agent-protocol), a [TypeScript agent runtime](https://github.com/kiliczsh/genui-agent-runtime-ts), a [Cloudflare backend](https://github.com/kiliczsh/genui-cloudflare-agent), and native [iOS](https://github.com/kiliczsh/genui-ios-app) / [macOS](https://github.com/kiliczsh/genui-macos-app) clients built on [SwiftUI renderers and component catalogs](https://github.com/kiliczsh/genui-kit).

- 🤖 [**claude-agents-sdk-swift**](https://github.com/kiliczsh/claude-agents-sdk-swift)
  Unofficial Swift Claude Agent SDK that drives the Claude Code CLI over its stream-JSON protocol with actors and AsyncSequence.

- 🕹️ [**codex-agents-sdk-swift**](https://github.com/kiliczsh/codex-agents-sdk-swift)
  Unofficial Swift client for the OpenAI Codex App Server protocol (JSON-RPC over stdio).

- 🧩 [**mcp-mongo-server**](https://github.com/kiliczsh/mcp-mongo-server)
  A Model Context Protocol server for MongoDB that lets AI assistants query and inspect MongoDB databases.

- 🧰 **uioption** <sub>🚧 work in progress, not public yet</sub>
  MCP server that gives AI assistants UI skill resources, design guidelines, and static assets for building interfaces with Tailwind CSS, plus a companion [Chrome extension](https://github.com/kiliczsh/uioption-extension) for injecting design variants and inspecting UI components on local dev pages.

- 🗺️ [**ailandscape.org**](https://ailandscape.org/)
  A comprehensive, interactive map of the AI tools ecosystem.
